# Know Your Farm brand assets

- `know-your-farm-icon.svg`: 64 × 64 viewBox; standalone sprout, sun and field mark. Use for the browser tab, app logo and small placements (16–48 px).
- `know-your-farm-logo.svg`: 420 × 80 viewBox; horizontal signature with the product name. Use where the text has room to remain readable, preferably at 240 px wide or greater.

Both files are scalable vectors. The warm light tile keeps the green and earth-tone symbol visible on light and dark backgrounds. Avoid squeezing the horizontal name into favicon sizes: use the symbol there. SVG files are editable and can be exported at any resolution without changing the source.

The interface name, sidebar, browser metadata and Mr Corn system instructions now say Know Your Farm. Historical scientific source files and previous reports retain their original wording for provenance. No model data, algorithms, state keys or navigation routes are renamed.
