# Versiones previas del ajuste por suelo

`r1_ajuste_suelo.py` y `r2_parsimonioso.py` son las dos primeras versiones de la fórmula que ajusta el
rendimiento según el suelo. Se guardan para mostrar por qué se llegó a la versión final
(`modelo/calibracion/r3_calibrar_y_validar.py`). Escriben `modelo_suelo_prueba.json` aquí mismo; no tocan el modelo.
